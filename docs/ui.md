## /login — ログイン

- 「Googleでログイン」ボタンのみのシンプルな画面。
- ログイン後、許可リスト外のメールだった場合は「アクセス権がありません」を表示し、即サインアウト。
- 未ログイン状態で他のルートに来たら `/login` にリダイレクト。

---

## / — ダッシュボード（Phase 1の中核）

月選択（前月/次月ナビ + 当月デフォルト）を最上部に置き、以下を縦に並べる:

1. **月次サマリーカード**: 収入 / 支出 / 収支差 / 貯金目標との差。★特別出費月はバッジ（例: 「★ 指輪(73万円)」）を表示 — Excelメモシートの「特別月を見える化」要望に対応。
2. **カテゴリグループ別支出（円グラフ）**: `categories.json` のグループ単位。色は `groups[].color` を使用。振替グループは除外。
3. **予算バー**: グループごとに予算(`budgets.json`)に対する消化率を横棒で表示。超過は強調色。
4. **月次推移（棒グラフ）**: 直近12ヶ月の収入/支出。特別出費月にマークを付け、「特別出費を除いた支出」の切り替えトグルを付ける（通常月の実力値を見るため）。

集計ルール（重要）:
- `group: "excluded"`（Card Payment / Transfer）は集計から除外。
- `isSpecial: true` の取引は「特別出費除外」トグルで除外できる。

## /transactions — 明細一覧

- 月・カテゴリグループ・口座・キーワードでフィルタ。
- 一覧行: 日付 / カテゴリラベル / 説明 / 金額（支出は赤系、収入は緑系）。
- 行タップで編集モーダル: カテゴリ変更、★特別出費フラグ + メモの付与、削除。
- 手動追加ボタン（現金支出などCSVに乗らない分の入力用）。
- 保存操作は編集セッション単位でまとめて `PUT /api/data`（1操作1コミットにしない）。

---

## /import — CSVインポート

- ファイル選択 or テキスト貼り付けの両対応（元Excelでは「CSV貼り付け」運用だったため貼り付けは必須）。
- 対応形式: `settings.json` の `importProfiles`（`#, Date, Amount, Account Currency, Description, Memo, Receipt, Category, Account Name, Account Number, Work`）。
- 取り込みフロー:
  1. パース結果をプレビュー表示（件数・期間・新カテゴリの有無）
  2. **重複検出**: `date + amount + description` が既存と一致する行は「重複の可能性」として除外候補に
  3. 未知のカテゴリは警告表示し、`categories.json` に `group: "other"` で自動追加
  4. 確定で `transactions/{year}.json` に追記して保存

## /salary — 給与推移

- 折れ線: 支給合計 / 差引支給額（手取り）の推移。賞与は別系列 or マーカー。
- 積み上げ棒: 控除内訳（社会保険 / 所得税 / 住民税 / その他）。
- 給与体系（ML7〜ML10）の変化点を注記表示。
- 給与明細の手動追加フォーム（Excelの列構成に準拠、`salaries.json` に追記）。

---

## /assets — 資産推移

- `months.json` の `balanceStart` / `balanceEnd` から口座残高の折れ線グラフ。
- ★特別出費月には注記（例: 2025-10 「家購入」で残高が大きく減った理由が一目でわかる）。
- 月末残高の手動入力フォーム。

---

## /settings — 設定

- **カテゴリ管理**: 英語カテゴリ → 日本語ラベル・グループの編集。グループの追加・色変更。
- **予算設定**: グループ別月間予算と貯金目標（`budgets.json`）。
- **口座管理**: 口座名の追加・編集。
- ログアウトボタン。

---

## /analysis — AI分析（Phase 2）

- 上部: 月選択 + 「この月を分析」ボタン → `/api/analyze` をSSEで受信しMarkdown表示（4段構成: 事実→傾向→アクション→将来影響）。
- 下部: チャットUI。分析結果に続けて自由に質問できる（「食費が多いけどどう減らす?」）。会話履歴はフロントのstateに保持（永続化はPhase 2では不要）。
- ストリーミング中はテキストが逐次描画されること。
- 分析結果の下に「かかったコスト目安」を小さく表示（任意）。

---

## /simulator — 将来シミュレーター（Phase 3）

- ライフイベント入力（`life-events.json`）: 住宅ローン（借入額・金利・期間）、出産・教育方針（公立/私立）、収入変化。
- 過去実績（直近12ヶ月の平均収支、特別出費除外）をベースラインとして3〜5年の月次キャッシュフローと累積資産を折れ線で表示。
- **スライダーで前提を動的変更**: 月の貯金額 / 食費削減額 / ローン繰上返済額 → グラフが即時再計算。
- シナリオ比較: 「現状維持」vs「改善案」の2系列を重ねて表示。
- 「AIに講評してもらう」ボタン → シナリオ要約を `/api/chat` に渡して解説を得る。

## デザイン方針

- 落ち着いたトーン（家計データを長時間見る画面なので彩度を抑える）。ダークモードは任意。
- グラフの色はカテゴリグループごとに固定（`categories.json` の `color`）。
- 金額表示: 3桁区切り + 円。支出は `-` 付き赤系、収入は緑系で統一。
- フォントはシステムフォントで良い（walk_diaryのような装飾フォントは不要）。
